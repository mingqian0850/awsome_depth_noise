# 建议研究路线图（Roadmap）

> 目标：**用模型学习真实深度相机的噪声模式，实现 (1) 噪声压制与 (2) 噪声 Real2Sim（向仿真传感器注入符合真实物理的噪声）**。
> 阶段 0–3 为一个完整闭环，预计可在单个传感器上验证；阶段 4 为扩展。

---

## 阶段 0：文献与基线（1–2 周）

- [ ] 精读核心论文：Khoshelham 2012（σ(d) 模型）、Plozza 2024（现代 iToF 建模）、主动立体 T-RO 2023（物理仿真）、LiDARsim 2020（真实重合成）、SelfReDepth 2024（自监督去噪）、RNSD 2025（扩散噪声合成）。
- [ ] 复现基线噪声模型：Habitat `RedwoodDepthNoiseModel`、`gazebo_noisy_depth_camera`（解析模型注入）。
- [ ] 选定目标传感器（建议一种 ToF 或主动立体，如 PMD / RealSense / Orbbec）+ 确定仿真器（Gazebo 或 Isaac Sim）。

## 阶段 1：真实数据采集与噪声表征（2–4 周）

- [ ] 建立数据采集协议（见 [datasets.md](datasets.md)）：
  - 静态场景多帧采样（≥100 帧/场景）→ pseudo-GT + 噪声残差；
  - 平面标定板多距离扫描 → σ(d)、bias(d)；
  - 材质/反射率靶 → 缺失率 p(d, reflectivity)、飞点概率；
  - （可选）高精度真值（结构光投影 / 激光扫描）。
- [ ] 噪声分析输出：
  - σ(d) 曲线（与文献模型对比）；
  - 噪声的空间相关核、边缘飞点统计；
  - 缺失/空洞的空间与条件分布；
  - （ToF）多径偏差模式（凹角/凸角）。
- [ ] **交付物**：传感器噪声分析报告 + 噪声数据集（残差/掩码/元数据）。

## 阶段 2：噪声建模与 Real2Sim 注入（4–8 周）

- [ ] **基线注入**：解析模型（σ(d)+缺失+相关核）写入仿真器插件，A/B 对比"无噪声 vs 解析噪声"。
- [ ] **学习式注入（研究核心）**：
  - 方案 A（生成式）：条件扩散/流模型，条件 = (距离, 反射率, 邻域几何特征)，学真实残差/缺失分布；在 RGB 域先例（RNSD/Noise Flow）基础上迁移到深度/点云；
  - 方案 B（混合）：物理模型结构 + 学习参数/残差（物理仿真管线 + 数据驱动标定）；
  - 方案 C（重合成，可选）：场景重建（NeRF/GS）+ 重渲染保留真实噪声。
- [ ] **注入逼真度评估**（关键）：
  - 分布指标：点云 FID/MMD、σ(d) 曲线匹配、缺失率匹配、自相关函数匹配；
  - 行为指标：注入噪声后下游模型（去噪网络 / SLAM / 分割）的表现退化曲线是否与"真实数据 vs pseudo-GT"一致；
  - 消融：各噪声分量（随机/偏差/缺失/飞点/多径）对下游任务的贡献。

## 阶段 3：噪声压制（Denoising）（4–8 周）

- [ ] 训练协议：
  - 自监督：Noise2Noise 两帧协议（真实数据直接训练）；
  - 弱监督：pseudo-GT（多帧平均）；
  - 监督（可选）：高精度真值；
  - 方法池：SelfReDepth 类深度修复、RADU 类 ToF 去噪、点云分数方法（ScoreDenoise / Noise2Score3D）。
- [ ] 评估：MAE / RMSE（对 pseudo-GT 与真值）、σ(d) 压缩比、点云 F-score / Chamfer、下游任务（SLAM 轨迹误差、抓取成功率）。
- [ ] **交叉验证闭环**：用阶段 2 的注入噪声训练去噪模型 → 在真实数据上评估 → 反馈修正噪声模型（real2sim ⇄ denoising 闭环）。

## 阶段 4：扩展与发布（持续）

- [ ] 多传感器泛化（ToF ↔ 主动立体 ↔ LiDAR），验证噪声模型的迁移性；
- [ ] 噪声模型插件开源（对接 Habitat / Gazebo / Isaac Sim），支持型号化配置文件；
- [ ] 发表/开源数据集与基准（噪声表征 + 去噪 + 注入评估）。

## 里程碑（Milestones）

| 里程碑 | 内容 | 完成标志 |
|---|---|---|
| M1 | 噪声表征报告 + 数据集 | σ(d)/缺失/飞点统计齐全，可复现 |
| M2 | 解析注入基线 | 仿真器输出带噪深度，下游任务差异可测 |
| M3 | 学习式注入 | 分布指标显著优于解析基线（或同水平但可泛化到新场景） |
| M4 | 自监督去噪 | 真实数据上 σ(d) 显著压缩，下游任务提升 |
| M5 | 闭环验证 | 注入噪声训练的去噪模型在真实数据上有效 |

## 风险与对策

| 风险 | 对策 |
|---|---|
| 缺少高精度真值 | 自监督两帧协议（Noise2Noise）规避；多帧平均作弱真值 |
| 噪声与场景内容耦合过强 | 条件生成模型显式加入反射率/几何条件；扩大场景多样性 |
| 注入噪声"看起来像"但下游不匹配 | 行为指标（下游退化曲线）作为主要评估 |
| 不同传感器噪声结构差异大 | 单传感器聚焦验证，再评估迁移；型号化插件设计 |
